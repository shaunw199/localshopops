1. The service

LocalShopOps provides operational tools for independently owned Etsy sellers, including authorized order and sales review, listing reads, draft creation, seller-confirmed listing and inventory edits, reports, and production or fulfillment coordination. Supported batch edits are limited to one authorized shop. Publishing, when enabled, is limited to one live draft at a time after a fresh Etsy read, a fee warning, and a separate second confirmation. Available functions may change as the service is improved and as Etsy API capabilities or policies change.

2. Seller authorization

Each seller must connect only an Etsy account and shop that the seller is authorized to operate. Etsy access is granted through Etsy Open API v3 using Etsy's OAuth 2.0 Authorization Code flow with PKCE. Users must not provide Etsy passwords to LocalShopOps or attempt to transfer API credentials between applications or users.

3. Independent seller accounts

Each LocalShopOps seller account is independent. A user may access only shops explicitly authorized for that account. Users must not attempt to view, obtain, copy, or modify another seller's data or bypass shop-level access controls.
